Syntra

Syntra (ранее Game Library) — персональное приложение для Windows для организации библиотеки игр, запуска игр и управления резервными копиями сохранений.

Google Drive

При добровольном подключении Google Drive приложение может сохранять резервные копии игровых сохранений в аккаунте пользователя.
